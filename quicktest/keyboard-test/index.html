How to use the keyboard test

Simply press every key on your physical keyboard, one at a time. Each key lights up blue while held down, then turns green once released, marking it as tested. The progress counter tracks how many keys you've pressed, so you can systematically check the whole keyboard.

Why test your keyboard

Keys can fail silently — a sticky spacebar, a dead letter key, or a shift key that only sometimes registers are all things you might not notice until you're mid-sentence. This test is especially useful after spilling liquid near a keyboard, or buying a used laptop or mechanical keyboard.

Troubleshooting a key that won't register

  • Key doesn't light up at all: physically inspect it for debris underneath — this is the single most common cause of a "dead" key.
  • Key lights up here but doesn't type in other apps: check for keyboard remapping software or OS-level shortcuts that may have reassigned that key.
  • Multiple keys stop working together: this can indicate "ghosting," a hardware limitation — try pressing keys one at a time instead of together.
  • External keyboard not responding: check the USB or Bluetooth connection, and confirm it's recognized in your operating system's device settings first.

Frequently asked questions

Does this log or store what I type?

No. Key presses are only used to light up the diagram on this page — nothing you type is recorded, logged, or transmitted.

Will this work with a non-US keyboard layout?

Yes — the diagram shows a standard US layout for reference, but the test reads your keyboard's actual physical key codes, so it works regardless of your keyboard's printed layout or language.

What does "key rollover" mean?

It refers to how many keys a keyboard can register accurately when pressed at the same time — important for gaming, less relevant for everyday typing.
